# Security playbooks: review, hardening, triage

Paths are relative to the playbooks skill.

- `references/security/security-review.md` — Adding authentication, handling user input, working with secrets, creating API endpoints or payment features: the checklist.
- `references/security/command-guard.md` — A command guard or policy hook blocks harmless work or lets a dangerous command through: reproduce, corpus first, fix the reading, replay.
- `references/security/cloud-infrastructure.md` — Deploying to a cloud platform or configuring IAM, secrets, networking, logging or CI/CD pipelines.
- `references/security/bounty-triage.md` — Hunting exploitable, bounty-worthy issues in a repository: remotely reachable vulnerabilities first.
