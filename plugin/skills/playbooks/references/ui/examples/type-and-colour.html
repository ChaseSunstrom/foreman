What this shows

  • Type scale: seven named steps from one base and one ratio; leading falls and tracking tightens as size rises.
  • Pairing: a sans for everything, a mono only for amounts and hex, both with tabular figures.
  • Palette roles and the proof: components use roles; each pair is measured in both themes.
  • Reserved status colours: red, amber and green appear only on status, each with a symbol and a word.
  • Dark mode: a second palette on the same roles, not an inversion; no pure black, no pure white.
Tallyhouse is invented. This page is a worked example of the type-and-colour playbook.
