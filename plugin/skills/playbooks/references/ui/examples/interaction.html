      What this shows

      • Feedback. The button looks pressed in the same frame, shows its busy label at once, and the result appears beside it, not in a corner.
      • One press, one action. While sending, a second press does nothing; the counter proves it.
      • Forms. Labels above, hints before typing, one column. A field is checked when you leave it with something in it, never while you type the first time, and an error clears as soon as the value is good.
      • Errors say what to do. "Enter an email address like name@example.com", never "Invalid". Each error has an icon and the word "Error", not red alone, and the submit button is never disabled to hint at them.
      • Keyboard. Tab follows the page, Enter submits, a skip link comes first, and the error summary takes focus with a link to each field.
      • Phone. At 360 px every control is 44 px or taller, text is 16 px, and the main button follows the last field. Under reduced motion the press and the nudge become a tint.
