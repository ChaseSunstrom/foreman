    The storyboard

    tSubjectTokensReduced

    Focus: moves to the next row at t = 0; the leaving row is inert at once. Interruption: Undo (or Ctrl+Z) mid-exit reverses from where the row is; nothing restarts.

    What this shows

    • Every motion has a cause. Press, delete, undo, reload: nothing moves on its own.
    • Timing vocabulary. Each duration and curve is a named token in :root; a raw ms appears only there.
    • State to motion. Exit, move, enter and wait each use their row of the table. The reload list arrives with a stagger capped at six.
    • Compositor only. Only transform and opacity move; the gap closes with FLIP, not a height transition.
    • Loading. Nothing shows for the first 300 ms, then skeleton rows the same size as the real ones, held at least 400 ms.
    • Reduced motion is its own path. The switch above sets data-motion; --shift, --pop, --travel and --stagger go to rest and every row keeps its fade or tint.
