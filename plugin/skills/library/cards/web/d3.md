D3: data-driven SVG and canvas via scales, axes, shapes and joins; best used for the math, with the framework owning the DOM.

## Verify
- `npx tsc --noEmit`: with `@types/d3` (the d3 modules are untyped otherwise).
- `npx vitest run`: scale, layout and data-transform tests in `jsdom` or pure.
- `npx playwright test`: the chart renders marks and axes in a real browser.

## Test first
Keep data prep and scales in pure functions and test them; check rendered marks via the DOM.
```ts
import { expect, test } from "vitest";
import { makeScales } from "./scales";

test("y scale maps max to the top margin", () => {
  const { y } = makeScales([{ v: 0 }, { v: 50 }], { height: 200, margin: 20 });
  expect(y(50)).toBe(20);
  expect(y(0)).toBe(180);
});
```
For rendered output: `d3.select(svg).selectAll("rect").size()` should equal the datum count.

## Do
- Use `d3.scaleLinear`, `scaleBand`, `scaleTime` with explicit `.domain()` and `.range()`.
- Bind data with `selection.join("rect")` (enter, update, exit in one call) and a key function: `.data(rows, d => d.id)`.
- Draw axes with `d3.axisBottom(x)` into a `<g>`; format with `d3.format` and `d3.timeFormat`.
- Use shape generators (`d3.line`, `d3.area`, `d3.arc`, `d3.pie`) instead of hand-built path strings.
- Define margins as a convention object and a `viewBox` for responsive scaling.
- Import only needed modules (`import { scaleLinear } from "d3-scale"`) to cut bundle size.
- In React or Vue, compute geometry with D3 and render elements in the framework; limit direct D3 DOM work to a ref'd container inside an effect with cleanup.
- Add titles, labels and `role="img"` with `aria-label`, plus a data-table fallback.
- Use `d3.csv` and `d3.json` with row conversion, or `d3.autoType`.

## Avoid
- D3 v3/v4 idioms (`d3.scale.linear()`, `d3.event`, `selection.enter().append()` chains with merge): removed. Use `scaleLinear`, the event argument in handlers and `join`.
- Letting D3 and React both mutate the same DOM nodes: they fight. Split ownership.
- Data joins without a key on reorderable data: marks bind to the wrong rows. Pass a key function.
- Hardcoded pixel sizes: no resize. Use `viewBox` or measure the container.
- Missing `.nice()` or explicit domains: ragged axes, or bars starting above zero. Set bar domains to start at 0.
- Re-running the whole render appending nodes with no clear: duplicates. Use `join` or clear first.
- Color-only encodings: inaccessible. Add labels, patterns or direct annotations.

## Review
- [ ] Scales and transforms are pure and unit-tested.
- [ ] Joins use keys and `join`, with no duplicate nodes on re-render.
- [ ] Bar charts start at zero; axes are labeled with units.
- [ ] Only one library owns each DOM subtree.
- [ ] The chart has an accessible name and a text alternative.
