Docusaurus: a React and MDX documentation site where broken links fail the production build.

## Verify
- `npm run build`: the production build runs and checks links (`onBrokenLinks` defaults to `throw`).
- `npm run start`: dev server with hot reload.
- `npm run serve`: serves the built output locally, to test what ships.
- `npx docusaurus build --locale en`: builds one locale when i18n is on.
- `npx tsc --noEmit`: the TypeScript config and components type check (if used).

## Test first
Practice check: a broken internal link must fail the build.
```sh
printf '[x](./does-not-exist)\n' > docs/_probe.md
npm run build; echo $?        # expect non-zero
rm docs/_probe.md
```
Keep `npm run build` in CI. Test custom React components with Jest or Vitest and Testing Library.

## Do
- Keep `onBrokenLinks: 'throw'` and set `onBrokenMarkdownLinks` to throw or warn deliberately.
- Set `url` and `baseUrl` correctly for the host (a project page needs `baseUrl: '/repo/'`).
- Use `sidebars.js` or `sidebars.ts` for ordering, or autogenerated sidebars with `_category_.json` and front matter `sidebar_position`.
- Use `@site/` aliases and relative links to files (`./other.md`) rather than hard-coded URLs.
- Use versioned docs with `npm run docusaurus docs:version X` only when you need old docs.
- Use MDX components for repeated callouts; admonitions with `:::note`.
- Configure Algolia or local search only with real credentials from secrets.
- Pin Docusaurus packages together at the same version.

## Avoid
- Wrong `baseUrl`: the site builds but assets 404 on the host. Match the deployment path with trailing slash.
- Linking with absolute site paths that ignore `baseUrl`: use relative links or `useBaseUrl`.
- Mixed `@docusaurus/*` versions: cryptic runtime errors. Upgrade them together.
- Treating MDX like Markdown: `{`, `<` and `import` are parsed as JSX, so a stray `<` or curly brace breaks the build. Escape or use code fences.
- Committing `build/` and `.docusaurus/`: they are generated. Add them to `.gitignore`.
- Putting API keys in `docusaurus.config.js`: it is public. Only public client keys belong there.
- Using `trailingSlash` inconsistently: duplicate URLs and host redirects. Set it explicitly.

## Review
- [ ] `npm run build` passes with broken-link checks on.
- [ ] `url` and `baseUrl` match the host, verified with `npm run serve`.
- [ ] Docusaurus packages share one version.
- [ ] No secrets in config; generated folders ignored.
