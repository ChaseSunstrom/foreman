R packages and analysis projects: testthat tests, devtools and `R CMD check`, renv for reproducibility, lintr and styler.

## Verify
- `Rscript -e 'devtools::test()'`: runs `tests/testthat/` against the loaded source.
- `Rscript -e 'devtools::check()'`: full `R CMD check` (docs, examples, NAMESPACE, tests); errors and warnings must be zero.
- `Rscript -e 'lintr::lint_dir()'`: lint results (config in `.lintr`).
- `Rscript -e 'styler::style_dir(dry = "fail")'`: fails when files need restyling.
- `Rscript -e 'renv::status()'`: the lockfile matches installed packages.

## Test first
Tests live in `tests/testthat/test-<topic>.R`; create the scaffold with `usethis::use_testthat()`.
```r
test_that("parse_amount rejects blank input", {
  expect_error(parse_amount(""), "empty", class = "my_error")
  expect_null(parse_amount(NA_character_, strict = FALSE))
})

test_that("summarise keeps group order", {
  df <- data.frame(g = c("b", "a"), x = 1:2)
  expect_equal(summarise_by(df, g)$g, c("b", "a"))
})
```

## Do
- Put reusable code in a package (`R/`, `DESCRIPTION`, `NAMESPACE` generated by roxygen2: `devtools::document()`), not in sourced scripts.
- Document exports with roxygen tags (`@param`, `@return`, `@export`) and list every dependency in `Imports` with `pkg::fun()` calls.
- Use `renv::init()` and commit `renv.lock` for projects; run scripts with `Rscript`, not an interactive session.
- Vectorize; use `vapply` or `purrr::map_*` with a declared return type over `sapply`.
- Signal errors with `rlang::abort()` or `stop(call. = FALSE)` and a condition class tests can match.
- Set seeds (`set.seed()`) in tests and simulations; test snapshots with `expect_snapshot()`.

## Avoid
- `library()` inside package code: use `Imports` and `pkg::fun`. Reserve `library` for scripts and tests setup.
- `sapply` in code that needs a stable type: it returns a list or vector depending on input. Use `vapply`.
- `T`/`F` instead of `TRUE`/`FALSE`: they can be reassigned.
- `1:length(x)` or `1:nrow(df)` when empty is possible: yields `c(1, 0)`. Use `seq_along()` and `seq_len()`.
- `setwd()` and absolute paths in scripts or tests: breaks on other machines. Use `here::here()` or `testthat::test_path()`.
- `read.csv` defaults silently converting types: set `colClasses` or use `readr::read_csv(col_types = ...)`.
- `df[, 1]` on data frames: drops to a vector for one column. Use `drop = FALSE` or tibbles.

## Review
- [ ] `devtools::check()` is clean and `NAMESPACE`/`man/` are regenerated, not hand-edited.
- [ ] No `library()` calls, `setwd()` or global assignment (`<<-`, `attach`) in package code.
- [ ] Loops index with `seq_along` or `seq_len`.
- [ ] Random behavior has a seed, and tests do not depend on locale or time.
- [ ] New dependencies are in `DESCRIPTION` and `renv.lock`.
