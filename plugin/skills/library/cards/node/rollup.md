Rollup for library builds: ESM/CJS output, tree shaking, externals, plugin order.

## Verify
- `npx rollup -c`: all configured outputs build.
- `npx rollup -c --failAfterWarnings`: warnings (unresolved imports, circular deps) fail the build.
- `npx tsc --noEmit`: types, if using a transpile-only plugin.
- `npm pack --dry-run`: the tarball contains `dist` and nothing extra.

## Test first
Import the built artifact in a test to prove the public surface and format.
```js
import { test } from 'node:test';
import assert from 'node:assert/strict';

test('ESM build exports the public API', async () => {
  const m = await import('../dist/index.js');
  assert.deepEqual(Object.keys(m).sort(), ['parse', 'stringify']);
});
test('CJS build loads', async () => {
  const { createRequire } = await import('node:module');
  assert.equal(typeof createRequire(import.meta.url)('../dist/index.cjs').parse, 'function');
});
```

## Do
- Emit both formats for libraries: `output: [{ file: 'dist/index.js', format: 'es' }, { file: 'dist/index.cjs', format: 'cjs' }]`, and wire them to `exports`.
- Declare `external` for peers and dependencies (a function or `Object.keys(pkg.dependencies)` list).
- Add `@rollup/plugin-node-resolve` and `@rollup/plugin-commonjs` only when bundling dependencies; keep `commonjs` before plugins that need ESM.
- Use `@rollup/plugin-typescript` or esbuild plugin for TS, with declarations generated by `tsc`.
- Set `output.sourcemap: true` and `output.exports: 'named'` for CJS builds with named exports.
- Add `treeshake` defaults; mark pure modules with `"sideEffects": false`.
- Use `rollup-plugin-dts` to bundle `.d.ts` files if you ship one declaration file.
- Use ESM config (`rollup.config.mjs`) and `-c`; use `--configPlugin typescript` for `.ts` configs.

## Avoid
- Bundling peer dependencies (React, etc.): duplicates and breaks hooks. Keep them external.
- Importing a CJS dependency with `import { x }` without the commonjs plugin: "is not exported" error. Add the plugin or use a default import.
- `output.format: 'umd'` by default: seldom needed now. Ship `es` and `cjs`.
- Old plugin names (`rollup-plugin-node-resolve`, `rollup-plugin-commonjs`, `rollup-plugin-typescript2` mixes): use the scoped `@rollup/plugin-*` packages.
- Leaving circular dependency warnings: they cause undefined at load. Break the cycle.
- `exports` in `package.json` pointing at files the build does not emit: consumers get ERR_MODULE_NOT_FOUND. Verify with `npm pack --dry-run`.

## Review
- [ ] `exports`, `main`, `module` and `types` match emitted files.
- [ ] Peers and dependencies are external.
- [ ] Build fails on warnings.
- [ ] Both formats are loadable in tests.
- [ ] Declarations are generated.
