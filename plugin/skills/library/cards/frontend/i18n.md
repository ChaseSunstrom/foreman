Translatable UI: message catalogs with ICU plurals, Intl formatting, locale routing and RTL-safe layout.

## Verify
- `npx tsc --noEmit`: typed message keys catch missing or misspelled ids (when the library is configured for it).
- `npx i18next-parser`: extracts keys from source to catalogs, exposing unused and missing ones (when installed).
- `node -e "console.log(new Intl.NumberFormat('de-DE',{style:'currency',currency:'EUR'}).format(1234.5))"`: runtime Intl data works as expected.
- Pseudo-locale run (accented, 40% longer strings): overflow and hardcoded text show up visually.

## Test first
Assert plural and format rules in a language with more than two forms.
```ts
import { test, expect } from 'vitest';
import { IntlMessageFormat } from 'intl-messageformat';

const m = '{n, plural, one {# file} few {# files} many {# files} other {# files}}';
test('Polish plural categories', () => {
  const f = (n: number) => new IntlMessageFormat(m, 'pl').format({ n });
  expect(f(1)).toBe('1 file');
  expect(f(22)).toBe('22 files');
});
```

## Do
- Externalize every user-visible string, including `aria-label`, `title`, `alt` and validation messages.
- Use ICU MessageFormat for plurals, select and gender; whole sentences per message, with named placeholders.
- Format with `Intl.NumberFormat`, `Intl.DateTimeFormat`, `Intl.RelativeTimeFormat`, `Intl.ListFormat` using the user's locale.
- Set `<html lang>` and `dir`; use CSS logical properties so RTL mirrors automatically.
- Resolve locale from URL, then user setting, then `Accept-Language`; fall back through a chain (`pt-BR` to `pt` to default).
- Give translators context: key description, max length, screenshots.
- Lazy-load catalogs per locale and route.
- Sort and compare with `Intl.Collator`, not `<` or `localeCompare` without a locale.

## Avoid
- Concatenating fragments (`"You have " + n + " items"`): word order and plurals differ. Use one ICU message.
- `n === 1 ? 'item' : 'items'`: wrong for many languages. Use plural categories.
- Hardcoded date or number formats (`MM/DD/YYYY`, `1,234.50`): use Intl.
- Text in images or fixed-width buttons: German and Finnish expand. Allow growth.
- `toUpperCase()` for display: breaks Turkish dotted i and German sharp s. Use `toLocaleUpperCase(locale)` or CSS `text-transform`.
- Flag icons for languages: a language is not a country. Use language names in their own script.
- Using the key as the English fallback silently: shows raw ids in production. Fail CI on missing keys.

## Review
- [ ] No hardcoded strings or formats in components.
- [ ] Plurals, genders and variables use ICU, not concatenation.
- [ ] `lang`, `dir`, and RTL layout verified with a real RTL locale.
- [ ] Missing-key check runs in CI; fallback chain defined.
- [ ] Dates and money carry the right timezone and currency, not just the locale.
