# Five historical idioms of one layout

Use when the user wants the same screen shown through different eras of design, or a direction feels generic and
needs a lineage to argue from. Take the one layout the product needs (say a hero, three features and a footer) and
draw it five ways; each idiom below sets all five knobs, so the five come out far apart by construction.

| Idiom | Era | Grid | Type | Colour | Ornament | Motion |
|---|---|---|---|---|---|---|
| Swiss (International) | 1950s-60s | strict modular columns, flush left, ragged right | one grotesk (Helvetica-like), weight and size for hierarchy | black, white, one signal red | none: the grid is the decoration | none, or a hard cut |
| Bauhaus | 1920s | asymmetric blocks, diagonals allowed | geometric sans, lowercase headings | primaries (red, yellow, blue) on off-white | circles, squares, triangles as structure | elements slide in on their axis |
| Art Deco | 1925-40 | symmetric, centred, vertical rhythm | tall condensed display caps over a classic serif | gold or brass on black or deep green | sunbursts, stepped frames, fine double rules | slow fades, a gleam across metal |
| Memphis | 1980s | playful collage, overlapping shapes | bold geometric display, mixed sizes | clashing pastels and brights, black outlines | squiggles, confetti, terrazzo patterns | bouncy, springy, a wobble |
| Brutalist web | 2010s | the browser's own flow, visible structure | system or monospace, default sizes | raw: white, black, link blue, one loud colour | borders, tables, underlines as they come | none; hover is an inversion |

## Procedure

1. Name the one layout in a sentence (its blocks in order) so all five draw the same content.
2. Draft each idiom as a direction card (`cards.md` format), its five knobs from the row above and the product's own
   words in every block; never placeholder copy.
3. Check each against the product: an idiom whose ornament fights the content (Memphis for a bank's statements,
   Art Deco for a terminal tool) is shown, named as a stretch, never recommended.
4. Show the five side by side (`fm looks book` for looks that match an idiom; a preview page per card only when
   asked) and let the user pick one era, or blend two (one owns type, the other colour).

## Avoid

- Pastiche: quote an idiom's rules (grid, type, colour), not its famous posters; no fake distressed textures.
- Mixing eras inside one card: each card is one idiom, wholly.
