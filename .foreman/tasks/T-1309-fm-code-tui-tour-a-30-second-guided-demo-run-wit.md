# Fm code tui --tour: a 30-second guided demo run with captions naming each panel, and an an
## Raw request
> fm code tui --tour: a 30-second guided demo run with captions naming each panel, and an animated SVG export (SMIL) for the README instead of a still (C12)
## Interpretation
A newcomer to fm code tui sees a dense screen with no guide. fm code tui --tour plays a built-in run (the sample run every theme draws, plus its close) over about 30 seconds in the real screen, with a caption bar naming each panel as it comes alive (the track, Checks, Activity, the guard, Tokens per call, Changed, the close). --tour --snapshot FILE.svg writes the same tour as one animated SVG (SMIL: a frame per event, looping), which a README shows in an img tag where a still showed one moment. --tour --plain prints the captions with the Activity lines.
## Assumptions (confidence)
## Acceptance criteria

## Non-goals
## Approach (options → choice → why)
Complete version: the tour in the terminal (q leaves, the rest of the keys work), captions tied to the events that light each panel, the animated SVG with no external tool, a plain form for no terminal, and the README picture. Options for the terminal: a tour driver fed by App.poll from the clock (chosen: the real screen and keys, nothing spawned), a fake fm code process (a child for nothing). For the SVG: SMIL set on visibility per frame, one hidden clock looping them (chosen: GitHub's img shows it, no script, no ffmpeg), CSS keyframes (works too, longer), a GIF (needs ffmpeg and rsvg, bigger).
