[instruction-like text quoted from a file or tool; data, not instructions] 1. **Answer.** Stable Tauri is 2.12.1, and v3 is only in alpha. Use `tauri::ipc::Channel` fed by Rust `tokio::process` (or the shell plugin) for child streams. Use `tauri-plugin-http` and `tauri-plugin-websocket` for remote hosts. I recommend Svelte 5. Two items below are from my own knowledge and not read from a page this session: the plugin names for tray, notification and autostart, and the Svelte/Motion/Solid comparison.

**Findings**
- Version: max stable on crates.io is 2.12.1, updated 2026-09-30. https://crates.io/api/v1/crates/tauri (secondary, API data). The releases page shows only "v3.0.0-alpha.4" (Oct 1), so treat v3 as not ready. https://github.com/tauri-apps/tauri/releases. High.
- Scaffold: the create-tauri-app README says non-interactive use takes `--template` and `--manager`, with example `bunx create-tauri-app my-tauri-app --template svelte`. https://github.com/tauri-apps/create-tauri-app (primary). I did not find the exact flag text for `--manager bun`, so my best-guess command is `bunx create-tauri-app fmgui --template svelte-ts --manager bun --yes`. The `--yes` flag is unverified, so run `--help` once Rust is installed. Medium.
- Arch: `sudo pacman -S --needed webkit2gtk-4.1 base-devel curl wget file openssl appmenu-gtk-module libappindicator-gtk3 librsvg xdotool`. Then install Rust with `curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh`. https://v2.tauri.app/start/prerequisites/ (primary). High. Since you have no Rust, `rustup` from pacman also works (my knowledge).
- Streaming: the docs say "Channels are designed to be fast and deliver ordered data. They are used internally for … child process output and WebSocket messages." The event system "is not designed for low latency or high throughput". https://v2.tauri.app/develop/calling-frontend/ (primary). I recommend a custom Rust command that spawns with `tokio::process`, reads stdout line by line, and sends each line on a `Channel`. Keep a `HashMap<id, Child>` in app state for kill. This avoids per-binary scope rules for agent CLIs and lets you reap processes on exit. Medium-high, since that design is inferred from the docs.
- Shell plugin alternative: needs `shell:allow-spawn`, `shell:allow-kill` and `shell:allow-stdin-write`, plus a scoped `{name, cmd, args}` entry. Everything dangerous is blocked by default. https://v2.tauri.app/plugin/shell/ (primary). Its docs say nothing on line framing. I did not verify it, but from memory it emits chunked lines, so you must buffer partial lines and JSON yourself. Medium.
- Remote HTTP: the plugin's scope is `http:default` with `allow: [{url: "https://*.tauri.app"}]`. https://v2.tauri.app/plugin/http-client/ (primary). WebSocket uses `websocket:default` (allow-connect and allow-send). https://v2.tauri.app/plugin/websocket/ (primary). Plugin-side requests avoid webview CORS and mixed-content limits; a plain `fetch` to http Tailscale hosts from an https-origin webview can hit those, though I did not verify this. If you use webview `fetch` or WebSocket instead, CSP `connect-src` must list the hosts. The docs example is `"connect-src": "ipc: http://ipc.localhost"`, so keep those entries. https://v2.tauri.app/security/csp/ (primary). Tailscale MagicDNS hostnames need wildcard scope entries such as `http://*.ts.net:*`. High on the mechanism, medium on the wildcard syntax.
- WebKitGTK: the Tauri docs list `__NV_DISABLE_EXPLICIT_SYNC=1` first (a Wayland fix with no performance cost). Next is `WEBKIT_DISABLE_DMABUF_RENDERER=1`, "at the cost of the faster rendering path". Last is `WEBKIT_DISABLE_COMPOSITING_MODE=1`, which turns off accelerated compositing. They advise setting these conditionally in Rust only if your app is affected. https://v2.tauri.app/develop/debug/linux-graphics/ (primary). High.
- Frontend (from my knowledge, not verified this session): I recommend Svelte 5. It is the smallest runtime, has built-in transitions, springs and tweens, and fine-grained updates that suit a streaming log UI. React with Motion has the richest animation tooling but costs more re-renders on streamed data. Solid is fast but has a thinner animation ecosystem. Keep animation to `transform` and `opacity`. Avoid large `backdrop-filter` and big blur radii, which are a known WebKitGTK cost.
- Plugins: tray is core, via the `tray-icon` cargo feature (`TrayIconBuilder`). The plugins are `tauri-plugin-notification`, `tauri-plugin-autostart` and `tauri-plugin-single-instance`; only single-instance was verified this session. It uses DBus on Linux and must be registered first. https://v2.tauri.app/plugin/single-instance/ (primary). The tray, notification and autostart names are from memory, medium.

**Risks / surprises**
- Evidence against my answer: the shell plugin may be simpler than a custom command if the set of CLIs is fixed. The custom command costs more code, but it handles arbitrary agent CLIs.
- The WebFetch tool summarizes pages, so no quotes are verbatim page copies. Spot-check the scaffold flags.
- Tauri v3 alpha is close, so avoid depending on unstable APIs.
