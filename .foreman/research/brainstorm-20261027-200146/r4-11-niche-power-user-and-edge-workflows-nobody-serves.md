# Brainstorm — lens: niche: power-user and edge workflows nobody serves

- **Gate SQL and ORM migrations before they run** — FEATURE — value 4 — effort M — risk low — category: data migrations
  Why: assumption: repos with a migrations folder get no ordering or reversibility check, so a non-reversible or lock-heavy DDL step can reach a deploy unnoticed.
  Done when: a fixture migration that drops a column with no down step fails the gate and names the file and line.

- **Refuse edits to generated and vendored files and name the generator** — FEATURE — value 4 — effort S — risk low — category: generated code
  Why: assumption: a model that edits generated output gets its change silently reverted on the next regen, and the proof still passes.
  Done when: an edit to a file with a "generated by" header or under `vendor/` is refused with the regen command in the message.

- **Catch case-only renames that break on macOS and Windows** — FIX — value 4 — effort S — risk low — category: portability
  Why: assumption: a `Foo.py` to `foo.py` rename passes on case-sensitive Linux and breaks imports on case-insensitive filesystems.
  Done when: a fixture rename that collides under case folding fails the gate on every platform, not only the one it was made on.

- **Print machine-readable NDJSON from every fm command** — FEATURE — value 4 — effort S — risk low — category: scripting
  Why: assumption: power users script fm from cron, editors and CI, and parse human text that changes between releases.
  Done when: `fm status --json` emits one JSON object per line with a schema version field, and a test pins the keys.

- **Run the gate under a faked clock and several timezones** — FEATURE — value 3 — effort S — risk low — category: time bombs
  Why: assumption: tests that hard-code a year or depend on the local zone pass today and fail on the day they stop being true.
  Done when: a test asserting on a hard-coded year fails when the gate runs with the clock set forward one year.

- **Reuse a recorded fix when the same failure comes back** — FEATURE — value 3 — effort S — risk low — category: repeat failures
  Why: assumption: the same gate failure recurs across tasks, and each time the model re-derives the same fix from scratch.
  Done when: a second occurrence of a fingerprinted failure proposes the stored fix and the gate result names which fix was reused.

- **Complete task ids, verbs and playbook names in the shell** — CLEAN — value 3 — effort S — risk low — category: shell completion
  Why: assumption: a power user types `fm task` and a T-number from memory many times a day, and the help output is the only lookup.
  Done when: tab after `fm task ` lists open task ids with their titles in bash and zsh.

- **Edit notebooks by cell and diff them by cell** — FEATURE — value 3 — effort M — risk med — category: notebooks
  Why: assumption: `.ipynb` JSON edits are unreadable in a raw diff and the gate ignores their output cells.
  Done when: a change to one cell's source produces a diff that names only that cell and runs the notebook's test cells.

- **Give each submodule its own state, lock and gate** — FEATURE — value 3 — effort M — risk med — category: nested repos
  Why: assumption: a task that touches a submodule is gated against the parent's state, so its pinned commit and its own tests are never checked.
  Done when: a change inside a submodule runs that submodule's gate, and a parent pin pointing at a dirty submodule is flagged.

- **Queue offline and run on reconnect** — FEATURE — value 3 — effort M — risk med — category: offline work
  Why: assumption: a laptop on a train can write tasks but cannot call a model, and the queue refuses to start rather than holding them.
  Done when: tasks written with the network off stay queued, and they start once a connectivity check passes, with their context pack cached before the connection drops.

- **Query the journal with a small filter** — FEATURE — value 3 — effort M — risk low — category: journal queries
  Why: assumption: the journal holds the answers power users want, such as which gate failed most this month, but reading it means grepping JSON.
  Done when: `fm query 'gate == "fail"' --since 7d` returns the matching events and nothing else.

- **Wild: show the queue on the keyboard's Caps Lock light** — FEATURE — value 2 — effort S — risk low — category: ambient signal
  Why: wild. assumption: a Linux user who looks away from the terminal misses "needs you", and a keyboard LED is a signal they already see.
  Done when: a run that needs the user turns the LED on through `/sys/class/leds` and turning it off clears the state.

- **Wild: draft a question to whoever last understood a file, and never send it** — FEATURE — value 2 — effort M — risk low — category: bus factor
  Why: wild. assumption: `git blame` plus recent authorship shows who last understood a file, and a stalled task often needs that person's answer.
  Done when: a stalled task on a file with a clear last author produces a draft question in `fm` that names the author and the blame range, and nothing is sent.

- **Wild: accept requests in any language and file them in the repo's language** — FEATURE — value 2 — effort M — risk med — category: multilingual intake
  Why: wild. assumption: a user who types in one language on a team that works in another loses meaning at intake, and the acceptance check drifts from the user's words.
  Done when: a request written in Portuguese is filed as a task whose title and acceptance check are in English, with the original kept verbatim beside them.
