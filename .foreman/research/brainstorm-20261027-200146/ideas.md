- Release a model run's edit leases when the run ends — Count runs that die holding edit leases; if none are left stranded, skip.
- Stop affected and evidence checks from queueing behind the machine-wide gate — Time affected and evidence checks while another run holds the gate; if waits stay under a second, skip.
- Show the next usage reset in `fm status` and resolve `defer --until reset` to it — Ask five users when they'd defer to a reset; if they just type a date, skip.
- Run `fm doctor` fixes that are safe without asking — Run `fm doctor` on ten repos and list its fixes; if most still need confirmation, skip.
- Let `fm quiet` read stdin — Pipe a script into `fm quiet` once; if nobody needs stdin, skip.
