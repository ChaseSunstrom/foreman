## Kill it fast (the quickest test that would show it isn't worth building)
- Write a stop-reason verdict on every session end — Grep last 20 session ends; if the stop reason is already recoverable from the transcript tail, a verdict file adds nothing.
- Gate "finished" on a goal-level closing audit by a cold reader — Run a cold reader on 5 finished goals; if it passes all 5 or flags only things the user never cared about, the gate is noise.
- Freeze the contents list as a sealed, versioned object — Check git/history of contents lists; if fewer than 1 in 10 are edited after creation, sealing solves nothing.
- Rate the plan for omissions before work starts — Have the rater score 5 old plans with known later additions; if it misses most of them, it's theater.
- Detect drift by tracing every task back to a contents item — Trace 10 recent tasks by hand; if every one maps trivially to a contents item, drift detection never fires.
- Add a gold-plating stop: marginal-value cutoff per goal — Count past goals where the extra work was later kept by the user; if most, a cutoff throws away wanted work.
- Re-inject a one-screen goal card every session until finished — Paste the goal card into 3 resumed sessions; if behavior is unchanged vs. no card, drop it.
- Wire unmet MUST clauses into the Stop hook as blockers — List unmet MUST clauses at the last 10 Stop events; if they're always empty or always unfixable, the hook only blocks or only idles.
- Make a finish-checklist a derived grid, not a remembered list — Diff a derived grid against the hand checklist on 3 goals; if they're identical, derivation buys nothing.
- Wild: Hold a pre-mortem and store its failure modes as clauses — Run one pre-mortem on a finished goal; if the failure modes are generic ("tests might fail"), kill it.
- Wild: Dead-man heartbeat that distinguishes asleep from dead — Check how often a session dies silently versus idles; if never, a heartbeat has no case to catch.
- Wild: Replay a finished goal against its own plan as a time-lapse — Ask whether anyone would watch one replay; if nobody asks, it's a demo, not a tool.
