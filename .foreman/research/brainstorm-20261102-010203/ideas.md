## Kill it fast (the quickest test that would show it isn't worth building)
- Thymus-test every new guard rule against the user's own history — Replay the user's last 30 days of approved commands against the rule set; if under 1% would have been blocked wrongly, the rules are already fine.
- Remember approvals by shape, not prefix — Cluster the last 200 approvals by prefix vs. shape; if the approval count doesn't drop by at least 30%, skip it.
- React to damage, not strangeness (danger model) — Grep incident logs for harm that had no foreign-looking precursor; if every harm was pattern-visible, a damage detector adds nothing.
- Require two signals before any warning (anergy) — Count past warnings that had only one signal; if over 90% were true positives, requiring two signals just delays them.
- Tag sibling bug sites after every FIX (complement cascade) — Take the last 10 FIXes and grep for sibling sites by hand; if fewer than 2 turn up, tagging isn't worth it.
- Let a global fever mode throttle everything — Check the logs for a time when clustered failures were followed by more failures within the same session; if there are none, a fever mode has nothing to react to.
- Quarantine one misbehaving part, not the whole system (inflammation) — Look at the last 10 bad outputs; if the bad part is rarely separable from the good, quarantine can't isolate it.
- Add a storm regulator over all alarms (T-regs) — Count alarm storms in the logs; if there are fewer than 3 per month, a regulator is over-engineering.
- Show a titer: which attacks have antibodies, and how stale — Ask the user whether they'd read a staleness table this week; if the answer is no, it's a dashboard nobody opens.
- Wild: Vaccinate lessons with an attenuated past incident — Check whether a synthetic past incident ever teaches anything the real incident log doesn't; if not, drop it.
- Wild: Publish a weekly autoimmune report — Draft one report by hand from the logs; if the user doesn't open it twice, kill it.
- Wild: Share signatures across the user's own machines (herd immunity) — Check if the user has more than one machine running this; if one, it's moot.
- Wild: Mature guard rules in a germinal-centre rehearsal — Run one rule through ten mutations by hand; if no variant beats the original on the replay corpus, it's wasted compute.
- Run negative selection on every new detector — Count how many detectors were added in the last quarter; if it's fewer than 3, a selection pipeline costs more than it saves.
- Require a second signal before a learner acts (tolerance/anergy) — Tally learners that acted wrongly on a single signal; if none did, anergy is theoretical.
- Vaccinate every learner nightly with attenuated poison — Inject one poisoned entry by hand into a learner; if the existing review already rejects it, nightly doses are redundant.
- Enter a whole-system fever on clustered harm — Check whether harm events cluster in time at all; if they're independent, there's nothing to trigger on.
- Regulate proactive output with one suppressor (T-reg) — Count the proactive outputs the user ignored last week; if few, there's nothing to suppress.
- Key memory on failure signature for a fast second response — Check if the same failure signature recurs across sessions; if under 20% repeat, fast second response rarely fires.
- Quarantine a bad lane's output locally (inflammation) — Check whether bad lane output ever leaked downstream before being caught; if never, local quarantine is redundant.
- Mature guard rules by affinity (clonal selection) — Compare rule versions to see if any ever improved over time with feedback; if not, selection has no signal.
- Grade responses on a ladder (complement cascade) — Check whether graded responses would have differed from the current block/allow outcome on the last 50 events; if they match, the ladder adds nothing.
- Wild: Export a signed antibody pack to a new repo — Ask whether a second repo exists that wants these rules; if none does, drop it.
- Wild: Use a naive-cell reviewer on the day's anomalies — Run one cold reviewer over a day's anomalies; if it finds nothing the main review didn't, skip it.
- Wild: Run an autoimmunity drill on each Foreman release — Look at whether a Foreman release has ever broken a user workflow through over-blocking; if never, a drill is premature.
- Graduate every new rule through a thymus exam — Same test as 14: if the replay corpus rarely rejects a new rule, the exam is a rubber stamp.
- Recognise a known failure in one line (memory cells) — Time how long it takes you to recognise a repeat failure from the log by eye; if it's seconds, an automated one-liner saves nothing.
- Warm the whole harness with a visible fever — Ask if the user would notice a visible fever indicator; if they never look at the status line, it's invisible.
- Require two signals before a noisy detector speaks (costimulation) — Check the precision of the noisiest detector; if it's over 80%, costimulation only hides true hits.
- Notice allergies: rules the user overrides by hand — Count the manual overrides per rule in the last month; if all rules have under 3, there's no allergy to find.
- Show the three lines a cold reader should check (antigen presentation) — Hand the cold reader the three lines for 5 past failures; if it misses the cause in over half of them, the choice of lines is wrong.
- Calm Foreman's own overreactions (T-regs) — Check whether Foreman has ever overreacted in the logs; if there are no cases, there's nothing to calm.
- Issue a vaccination card (wild) — Ask the user if they'd ever look at a card; this is cosmetic, so kill it unless they say yes.
- Light up local swelling on a file heat map (wild) — Count how many files recur across failures; if failures are spread evenly, the heat map is flat.
- Share learned bad signatures between my machines (wild) — Duplicate of 12; kill it unless there's more than one machine.
- Mutate a blocked command into its relatives overnight (wild, affinity maturation) — Generate 20 relatives of one blocked command by hand; if the existing rule already catches them all, mutation finds nothing.
- Negative-select every new rule before release — Same as 14: if the replay corpus never rejects a draft rule, skip it.
- Guard on damage signals, not just foreign patterns (danger model) — Same as 3: find harm that lacked a pattern precursor, or skip.
- Raise a session-wide fever after harm — Same as 17: if harm events don't cluster, session-wide fever fires on noise.
- Remember each incident as a memory cell with a pre-model fast path — Same as 19: if failures rarely repeat, memory cells rarely fire.
- Mutate and select guard rules against an evasion corpus (affinity maturation) — Build an evasion corpus of 20 samples by hand; if the current rules already catch over 90%, the loop has no headroom.
- Add a regulatory layer that caps reaction cascades (T-regs) — Count cascades in the last month that ran away; if none, a cap is solving a hypothetical.

- Wild: grow an immune-system page in the web UI — Ask whether the user opens the web UI daily; if they don't, a new page goes unseen.
