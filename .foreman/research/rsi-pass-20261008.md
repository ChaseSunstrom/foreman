  - Cause: `_reads_pipe_as_data` requires every other command in the whole script to pass `_writes_nothing` (`plugin/lib/fmguard.py:1245`). `_writes_nothing` accepts only `_DATA_TOOLS` (`:1184`).   - Change: restrict the check to the pipeline's own commands (`chain`) and to earlier commands that can set env or write files. Allow plain `rm` of literals, `pkill`, `sleep` and `echo`.
  - Effect: removes the 3× pipe-shell blocks; Claude no longer has to split the command.
  - Done when: a new `test_guard.py` case `pkill -f x; rm -f /tmp/a.log; curl -s u | python3 -c 'import json,sys; json.load(sys.stdin)'` is allowed, and `curl … | python3 -c 'import os…'` is still blocked.
