## Kill it fast (the quickest test that would show it isn't worth building)
- Show a one-screen decision card at plan accept — Hand-draw the card for 10 past plans; if users can't pick accept or reject from it without opening the full plan, drop it.
- Record whether deliberation changed the outcome — Diff the final plan against the first-draft plan across 30 closed tasks; if under 10% differ, deliberation isn't changing outcomes and tracking it is moot.
- Skip deliberation for S tasks and log the skip — Count how many S tasks were later reopened; if the reopen rate matches M tasks, skipping is unsafe.
- Keep an edge-case deck per task kind, built from reopens — Sample 20 reopens; if fewer than a third cluster by task kind, per-kind decks have no signal.
- Fill the 58 cells from live deliberation traces, not prose — Check whether traces carry cell-level info; if the traces are mostly prose, parsing them gives nothing structured.
- Explain blast radius in plain words — Ask 3 users to read 5 blast-radius blurbs; if they can't say what breaks, plain words add nothing.
- Let the user override depth with one word — Grep the logs for depth overrides already typed; if there are none, nobody wants the knob.
- Run a deliberation budget alarm — Plot deliberation tokens against outcome quality; if there's no correlation, an alarm just nags.
- Add a pre-ask precedent check — Search past asks for repeats of already-answered questions; if under 5%, a precedent check is overhead.
- Wild: add an "argue for the runner-up" button — Run the runner-up argument by hand on 10 plans; if it flips fewer than 1, the button is theater.
- Wild: build a steer-twin that flags plans violating a steer — Count steer violations in the last 50 plans; if there are zero, a twin has no work.
- Wild: replay the thinking as a scrubbable tree — Check whether anyone has ever opened the raw thinking; if not, a scrubbable tree won't get used.
- Add a "nothing to think about" receipt — Count tasks where deliberation found nothing; if rare, a receipt is noise, and if common, this duplicates idea 3.
- Ground every idea against what's built before it is shown — Take 20 ideas and grep each against the repo; if under 10% already exist, grounding filters nothing.
- Collapse the idea catalog into canonical clusters with repeat counts — Cluster the 60 ideas above by hand; if there are more than 40 clusters, there's no repetition to collapse.
- Scope "ideas so far" to the mission's capability — Check how often "ideas so far" crosses capabilities; if it never leaks, scoping is a no-op.
- Raise the plan-depth floor for self-filed and unattended tasks — Compare the failure rate of self-filed and unattended tasks against attended ones; if equal, no floor is needed.
- Check plans as files so hookless harnesses get the gate — Test whether the hookless harness skips plan files entirely; if it does, a file gate isn't enforceable.
- Remember rejected approaches and block their silent return — Count silent returns of rejected approaches in history; if there are none, the blocker has nothing to catch.
- Show a plan board in the web UI with strike and star — Check whether the web UI gets any traffic during planning; if users stay in the terminal, skip it.
- Add a `fm go` verb that takes the current leader mid-deliberation — Count mid-deliberation moments where a leader exists and users wanted to cut in; if there are no such complaints, drop it.
- Give weak models a scaffold for exhaustive thinking in `fm code` — Run the weak model with a scaffold on 5 tasks; if edge-case coverage is unchanged, the scaffold is dead weight.
- Watch a chosen approach's flip condition after close — Check how often flip conditions fire after close; if never, the watcher idles forever.
- Show-don't-ask: mock demos of each reading (wild) — Mock up demos for 3 ambiguous asks; if the cost per ask is more than the clarifying question, it loses.
- Write a fear headline per big plan and check it at close (wild) — Write fear headlines retroactively for 10 closed plans; if they're generic, the check is useless.
- Sleep on L plans and re-read them cold in the morning (wild) — Re-read 5 L plans cold the next day; if you change nothing, sleeping adds only delay.
- Draw the plan as a fork map — Draw a fork map for 5 plans; if most have a single path, there's nothing to draw.
- Name the save — Name the save on 10 past incidents; if you can't tell a real save from the plan's own claim, it's unverifiable.
- Write the "why this one" sentence — Read 10 existing plans; if the "why this one" is already stated, this is redundant.
- Pulse the blast radius as ripples — Check whether ripples add info beyond the blast-radius list; if not, cut it as decoration.
- Hover a plan step to light up the user's words — Test hover mapping on 5 plans; if steps don't trace to specific user words, the hover lights up nothing.
