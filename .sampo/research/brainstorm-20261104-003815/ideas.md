## Kill it fast (the quickest test that would show it isn't worth building)
- Run the funnel as ecological succession — Label last 200 funnel survivors by stage of origin; if succession stage doesn't predict survival better than the existing stage order, drop it.
- Stop generating when the rarefaction curve flattens — Plot unique-moon count vs. generations on the existing log; if the curve never flattens before budget runs out, the stop rule never fires.
- Sample the ecotones between filled grid cells — Count how many candidates already fall between filled cells; if under ~5% of output, there are no ecotones to sample.
- Force character displacement between near-duplicate moons — Pairwise-embed the current moons; if fewer than ~3% are near-duplicates, there's nothing to push apart.
- Keep a seed bank of dormant moons with germination predicates — Check the deferred pile for entries whose blocking condition later became true; if none did in past runs, dormancy buys nothing.
- Burn the deferred backlog on purpose and count resprouters — Re-run 20 deferred items unchanged; if under 1 in 20 now passes, resprouting is noise.
- Add a trophic energy pyramid across model tiers — Tabulate per-tier spend vs. survivors; if the existing cost-per-survivor table already shows the shape, the pyramid is just a chart.
- Wild: Gate promotion on quorum sensing across independent lineages — Check whether "independent lineages" ever agree on a promotion that a single lineage wouldn't have made; if not, quorum equals one vote.
- Wild: Grow a mycorrhizal lesson network between repos and lanes — Grep the lesson store for lessons reused across repos; if cross-repo reuse is near zero, no network exists.
- Wild: Run a Red Queen arms race between generator and critic — Run 5 critic-vs-generator rounds by hand; if the critic's pass rate doesn't move, there's no arms race, only drift.
- Wild: Hold a nurse-log week where Sampo builds scaffolds for future tasks — Look at whether any past scaffold was reused by a later task; if under 10% were, speculative scaffolding is waste.
- Compute a keystone score per verb from a simulated extinction — Remove the 5 most-used verbs in a replay; if the outcomes barely change, keystone scores are flat.
- Show the tower as a forest with age rings — Ask whether age-ring data (timestamps per node) exists today; if not, it's a logging project, not a view.
