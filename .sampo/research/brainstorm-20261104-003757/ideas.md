## Kill it fast (the quickest test that would show it isn't worth building)
- Queue installs as one signed grant manifest — Count the installs queued per session in the last 30 days of history; if it's mostly 0 or 1, a batch manifest has nothing to batch.
- Quarantine every candidate tool before it is offered — Run the last 20 offered tools through a plain `--help` plus a network-call grep; if none fail, quarantine is pure overhead.
- Require a failing negative control before a tool counts as tested — Hand-write a negative control for 5 existing tools; if more than 2 take over 10 minutes, the rule will be skipped in practice.
- Show the gap-to-tool pipeline as a tool shelf in the web UI — Show a mockup of the shelf to the user for 30 seconds; if they'd rather run `ls`, it's dead.
- Mine gaps from history, not from guesses — Grep history for "tool not found" or "command not found" and count distinct gaps; if fewer than 5 recur, there's nothing to mine.
- Export acquired tools to every harness as a host-neutral manifest — Name two harnesses that would actually consume the manifest today; if you can't, it's speculative.
- Decide build versus find with a priced estimate — Compare the priced estimates with actuals on 5 past builds; if they're off by more than 2x, the estimate is noise.
- Score small models on tool building with a scaffold ladder — Run 3 small models on one tool-building task with no scaffold; if all pass or all fail, the ladder has no gradient.
- Retire tools that never fire on a real path — Check the fire counts of existing tools in logs; if there are fewer than 10 tools, retirement is premature.
- Record tool provenance and drift — Diff the installed tool hashes across two weeks; if there's zero drift, provenance tracking is ceremony.
- Wild: Tool forge duel — Would the duel winner differ from just picking the cheaper build? Run one pair; if the outputs are equivalent, it's a toy.
- Wild: Ghost-install film — A film of an install is a screen recording; if `asciinema` already does it, stop.
- Wild: Overnight tool dreams — Run one overnight job; if the morning tools are untested stubs the user won't read, kill it.
- Wild: Pawn shop between machines — Name a concrete second machine the user owns that needs tools from the first; if there isn't one, kill it.
- Gate every card on a bare-model exam before it enters the store — Run one bare-model exam on 5 existing cards; if the pass/fail split doesn't match intuition, the exam isn't discriminating.
- Compile frontier traces into stepwise playbooks a small model walks — Compile one frontier trace by hand into a playbook and run a small model through it; if it derails by step 3, the idea fails.
- Fill the card grid by failure mining, not by writing — Mine 20 failures; if fewer than 3 cluster into the same cell, there's nothing to fill.
- Route cards by retrieval from the task, capped by the model's measured effective context — Measure retrieval top-3 hit rate on 10 tasks; if it's below 70%, routing hurts more than it helps.
- Grammar-constrain card-driven steps to a verb menu — Run the grammar-constrained and unconstrained arms on 10 steps; if the pass rates are within noise, the grammar is unneeded.
- Show per-card lift and decay on a Models/Cards page — Check whether any card has more than 5 runs; if none do, the lift chart would be empty.
- Re-measure cards when the served model changes, and retire the ones that stopped helping — Swap the served model once and rerun 5 cards; if the lifts don't move, re-measurement is wasted.
- Have the 27B write cards, and a different small model test them cold — Have the 27B write 3 cards and a cold small model run them; if it fails to use them at all, the loop is broken.
- Wild: Distil the scaffolded 27B's accepted runs into LoRA adapters per stack — Count accepted runs per stack; if under about 200, LoRA training is hopeless.
- Wild: A card tournament where cards for the same cell compete, losers are merged into winners — Check whether two cards for the same cell exist today; if not, there's no tournament.
- Wild: A "dumbest model" floor: find the smallest model that passes each card's task and print it on the card — Run one card down 3 model sizes; if the pass/fail pattern is non-monotone, "smallest passing" is meaningless.
- Wild: Let cards be written by the failing model itself as a post-mortem, then verified by retry — Ask a failing model for a post-mortem once; if the retry with it doesn't beat the plain retry, drop it.
- Ship a tool-gap ladder card — Check whether the ladder card text exceeds the small model's effective context; if it does, it won't be read.
- Add fill-in script skeleton cards — Take 5 past scripts and see if they share a skeleton; if they don't, skeletons won't fit.
- Standardize the install-grant request card — Compare 5 past grant requests; if they're already identical in shape, a standard card adds nothing.
- Gate every card on a measured lift — Run the lift measurement on one card; if the noise exceeds the effect with n=10, the gate blocks everything or nothing.
- Graduate repeated cards into scripts — Count cards that were invoked more than 3 times with identical steps; if none, there's nothing to graduate.
- Write per-model quirk cards from exam failures — Look at 10 exam failures; if the failures aren't model-specific, per-model cards are redundant with general ones.
- Retrieve cards at the failure, not at the start — Inject the card mid-run by hand on 3 failures; if recovery doesn't improve over the start-loaded card, kill it.
- Check built tools with a conformance card — Check whether built tools already have tests; if the conformance card is just "run the tests", it's a duplicate.
- Compile a frontier tool-building run into a branching playbook — Branch points in one frontier run: if there are fewer than 2 real decisions, it's linear and needs no branching.
- Lint design cards for a size and checker budget — Measure the card sizes today; if all are already under budget, the lint never fires.
- Wild: Hold a card duel, where two small models write rival cards for one gap — Run one duel; if the two cards are near-identical text, there's no diversity to compete.
- Wild: Dream shelf of pre-built tools — Pre-built tools for unknown gaps: check the hit rate against the last 20 gaps; if under 20%, it's wasted compute.
- Wild: Cassette cards, replayable recordings that a small model follows step by step — Replay one recording with a changed input; if the model can't adapt, cassettes are brittle.
- Run a paired replacement arm for each not-yet local model — List the models that aren't local yet; if there are fewer than 2, a paired arm is overkill.
- Climb a scaffold ladder per model — Run the ladder on one model; if it passes at rung 0 or never passes at all, there's no ladder.
- Ablate every small-model card — Count the small-model cards; if there are fewer than about 10, ablating each is cheaper to skip than to automate.
- Publish a frontier-parity curve — Plot two points; if you don't have a frontier baseline run yet, there's no curve.
- Batch exam arms by resident model — Count the distinct resident models in the exam; if it's 1, batching is a no-op.
- Measure whether the model knows it failed — Ask 10 failed runs "did you succeed?"; if the false-claim rate is under 10%, skip it.
- Add a zero-token structure arm — Run the zero-token structure arm once; if it matches the real arm's scores, the real arm is the waste, otherwise the structure arm is useless. Either way it's a single run.
- Run a paraphrase contamination arm — Paraphrase 5 tasks; if the pass rate doesn't change, contamination isn't a problem here.
- Score cost per verified pass — Compute cost per pass from existing logs; if the ranking equals the pass-rate ranking, the metric adds nothing.
- Wild: Run a nightly gladiator league — Nightly league needs budget; at $200 total, price one night's run, and if it's over 5% of that, kill it.
- Wild: Compile frontier wins into cards, then test them — Compile 3 wins into cards and test; if lift is zero on all 3, the compile step is the problem.
- Wild: Feed a poisoned card to test robustness — Poison one card and run it; if the model ignores it or always obeys it, the result is already known.
- Wild: Let a small model author scenarios — Have a small model write 5 scenarios; if more than half are unsolvable or trivial, drop it.
- Rule-of-three before any plugin gets built — Check how many past plugins were built after the third request; if most were built after the first, the rule would've blocked useful ones.
- Run a bare-host search before every `plugins find` — Time a bare-host search; if it takes more than the find itself or finds nothing, the step is dead weight.
- Keep a counterfactual receipt for each acquired tool — Write one counterfactual receipt; if it requires rerunning the task without the tool, the cost exceeds the tool's.
- Retire a small-model card when the model passes bare — Run 5 cards bare on the current model; if none pass bare, retirement never triggers.
- Put a retire-when predicate in every built tool's manifest — Write a retire-when predicate for 3 tools; if you can't state one for most, the field will be left empty.
- Expire queued install grants whose need has gone — Count queued grants older than 7 days; if none, expiry has nothing to expire.
- Prefer stdlib-only fallbacks for a missing tool — Check 5 recent missing tools for a stdlib solution; if most need real libraries, the preference is moot.
- Wild: let the small model impersonate the missing tool first — Have the small model impersonate 3 missing tools; if it fabricates output that looks right but isn't, it's harmful, so kill it.
