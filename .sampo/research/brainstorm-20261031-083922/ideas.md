## Kill it fast (the quickest test that would show it isn't worth building)
- Reopen a fix when its signature returns — Grep the last 30 days of fixes for signature recurrence; if fewer than 2 recurred, skip it.
- Turn each user correction into a failing-first test — Count the last 20 corrections that were actually testable; if under a third were, the failing-first rule is mostly ceremony.
- Replay corrections on every ship — Replay the last 10 corrections against current HEAD; if all still pass, a per-ship replay buys nothing.
- Justify every top-tier model pick — Compare the output of the top tier and the next tier down on 10 past picks; if graders can't tell them apart, drop the justification gate.
- Retire or recover stopped lanes on a clock — List stopped lanes from the last month and see how many were ever resumed; if almost none were, skip the clock.
- Age every blocked-on-user task and bundle the yeses — Check the age distribution of blocked-on-user tasks; if the median is under a day, bundling adds nothing.
