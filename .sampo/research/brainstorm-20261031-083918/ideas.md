## Kill it fast (the quickest test that would show it isn't worth building)
- Log every manual workaround as a capability miss — Grep last 20 sessions for manual workarounds; if fewer than 3 are real capability gaps rather than user preference, the log is noise.
- Search before build, enforced by a receipt — Hand-run search-before-build on 10 past builds; if the search found a usable tool in under 2, the receipt only adds ceremony.
- Make the install-grant queue unforgeable by the agent — Check whether the agent can already write to the queue file path; if a permissions change alone blocks it, no new mechanism is needed.
