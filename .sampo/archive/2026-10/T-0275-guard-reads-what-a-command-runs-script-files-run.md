# Guard reads what a command runs: script files run by bash/sh/source/. and python, and exec
## Raw request
> Guard reads what a command runs: script files run by bash/sh/source/. and python, and exec options (tar --to-command/-I/--checkpoint-action, ssh -o ProxyCommand/LocalCommand and -F, rsync -e, zip -TT, less +!, vim -c !, sed e), and code-loading env vars (BASH_ENV, ENV, PROMPT_COMMAND, LD_PRELOAD/LD_AUDIT, NODE_OPTIONS --require/--import, PERL5OPT, RUBYOPT, JAVA_TOOL_OPTIONS -javaagent) — research brainstorm-pass-3
## Interpretation
Commands can run hidden commands the guard never reads: options that execute a command string (tar --to-command / --use-compress-program / -I / --checkpoint-action=exec=, ssh -o ProxyCommand= / LocalCommand= / PermitLocalCommand / -F config, rsync -e / --rsh, zip -TT / --unzip-command, less +!cmd / LESSOPEN, vim/vi/nvim -c '!cmd' or +'!cmd', sed's e command and s///e flag, git -c core.sshCommand= / core.pager= / alias with !, find -exec is already handled) and environment variables that load code into the next program (BASH_ENV, ENV, PROMPT_COMMAND, LD_PRELOAD, LD_AUDIT, NODE_OPTIONS=--require/--import/-r, PERL5OPT, RUBYOPT, PYTHONSTARTUP for interactive, JAVA_TOOL_OPTIONS/_JAVA_OPTIONS -javaagent). The guard should read the embedded command string as a command (recursively, like bash -c) and treat a code-loading variable that names a file as running that file; where the payload can't be read, refuse the same way the guard already refuses an unreadable pipe into a shell.

## Acceptance criteria

## Approach (options → choice → why)
Options: (a) in check_bash, a table of exec-option extractors per program that yield the embedded command strings, each fed to check_bash(depth+1), plus a code-loading-env check on each simple command's assignments; (b) refuse every listed option outright (simple, but blocks harmless uses like tar -I zstd); (c) only document it. Choice: (a), falling back to (b)'s refusal only when the payload isn't a literal. Find how the guard already handles bash -c / sh -c / xargs / find -exec (_spawned_commands, _reads_stdin_code, _RUNS_STDIN) and reuse the same category and wording. MUST: before and after, run 'fm replay' over the real command corpus and report every command whose verdict changed; each newly denied one must be a real hidden exec, not a false positive (tar -I zstd, ssh host with no -o, rsync -av, sed -e 's/a/b/' must stay allowed). Add labelled guard cases with fm guard wrong for at least 8 vectors (block) and 6 harmless look-alikes (allow).
