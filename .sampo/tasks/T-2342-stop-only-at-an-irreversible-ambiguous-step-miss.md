Failure modes:

- Git-dependent verdicts go wrong. A file that is untracked or gitignored, or a run outside a repo (this working directory is not a git repository), makes "recoverable" look true or false incorrectly. The classifier needs an explicit "no git" branch.

- Hook latency regresses. Calling git inside the `fmhooks.py` hot path pushes `bench_hooks.py --runs 20` over its threshold. Separately, a changed output format breaks `fm replay` and the `roundtrip.py` e2e gate.
