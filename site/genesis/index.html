    D · Louhi, the exam

    Held-out repos decide “done”

    sampo exam gen plants defects in throwaway repos in six languages (Python, JS, TS, Ruby, Rust, C) and keeps the answer key outside each repo; a third of every kind is held out. Each agent's answers are graded against the keys: found, false alarms, fixed, tests written first. A model with no tools writes every kind of scenario itself (bugs, holes, slow code, missing packages, untested and clean code, false docs, flaky tests, vague, ambiguous and out-of-reach requests, asks for what already exists, three-part requests and scheduled work, and the README and request lines of the projects Rune itself is graded on), kept only when a check passes them, and only those decide the scorecard: Sampo's own templates never grade Sampo. The same agent, with and without Sampo, answers the same held-out repos, each score with its cost.
