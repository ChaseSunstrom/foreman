Sampo, formerly Foreman · discipline for coding agents

Your coding agent, with a smith on the job.

Sampo is the discipline layer for coding agents: Claude Code, Codex, Gemini CLI, opencode, or its own Smith on any model. It makes the agent plan before it edits, prove its work with commands it actually ran, stay on one task at a time, and keep going through the queue until the work is done or needs you.

How it works

Every request walks the same eight stations

A plain request, a tagged list or a whole backlog all go the same way down the road, from the mine to the record house. Each station is a step the agent can't skip: the hooks refuse an edit with no plan, and a close with no proof.

  1. I

    Capture

    The request becomes a task with a type and a size.

  2. II

    Expand

    What done means, and the command that proves it.

  3. III

    Ground

    Checked against the real code before planning.

  4. IV

    Plan

    Steps, scope and risks; big work weighs its approaches.

  5. V

    Execute

    Edits only inside an active task, test first.

  6. VI

    Verify

    Commands run and recorded, then independent audits.

  7. VII

    Reflect

    What slipped and why becomes a lesson or a follow-up.

  8. VIII

    Record

    Docs, changelog, commit, and the exact place to resume.

Smith

What the Smith holds your agent to

Left to itself, a coding agent edits before it understands, says tests pass without running them and chases every new idea halfway. The Smith runs the task loop, and Sampo's hooks make the right way the only way.

Plans first
Every request becomes a brief before any edit: its type and size, what done means, the command that proves it, and the steps. An edit with no active task is refused.
Proves it
Evidence is a command Sampo ran and recorded, not a sentence. A fix needs a test that failed first.
Stays on task
One active task. New requests go to the inbox instead of being chased; NOW: switches on purpose.
Never loses its place
State lives on disk, so after /compact or in a new session the agent resumes at the exact step.
Keeps going
Drive mode works through the whole queue. In full auto it decides, records why, and saves what only you can approve for one summary at the end.
Learns
Your corrections, its own friction and every reviewer's findings turn into fixes, tripwires and lessons the next task reads.

Many hands, one Smith

Independent tasks run side by side: builders work in their own worktrees, test-first, and hand back a commit. Every branch gets an independent review before Sampo merges it and reruns the checks. 414 lanes merged so far.

Many hands, one Smith

Independent tasks run side by side without stepping on each other.

  • Builders in their own worktrees. Each takes one planned task, works it test-first and hands back a commit.
  • Reviewed before it lands. Every branch gets an independent review; findings go back to its builder, then Sampo merges and reruns the checks.
  • Resumable. A stopped session picks its lanes back up where they were.

Ward

A Ward built for bypass mode

Sampo is meant to run without permission prompts, so the brake has to be real. Press a command to put it through the Ward again.

Reads what actually runs
Bash commands, file edits, the scripts a command calls and the hidden ways to run code, such as tar -I, find -exec and BASH_ENV.
Fails closed
If the Ward crashes or times out, the call is blocked, not waved through.
Only you lower it
The agent can't grant itself edits to Sampo, a push, or a lighter posture; those wait for your yes.
Checked against real use
Every change to the Ward replays thousands of real commands to show what it would newly block or allow.

570 commands blocked on Sampo's own repo so far. The most common kinds:

Where the names come from

Old as myth, precise as code

The names come from the Kalevala, where the Sampo is a mill that grinds flour, salt and gold from nothing. Ilmarinen the smith forged it, so the task loop is the Smith. Väinämöinen sang runes that made things, so the prompt tower is Rune. Louhi set impossible tasks, so the exam is Louhi. The stolen sun and moon were forged anew, so the moonshot catalogue is Moons. Lost words were fetched back from the underworld, so the ideas waiting on a blocker live in the Underworld. And the guard at the gate is the Ward.
