Features

Everything Foreman does

Each page shows what one part of Foreman does, how it works, the commands, and charts from Foreman's own record of building itself.

PlanningIntake turns a request into a brief with a type, a size, criteria and the commands that prove them.ProofEvidence is a command Foreman ran and recorded; a fix needs a test that failed first.The guardEvery command and edit is read before it runs; dangerous ones are refused and destructive git saves your work first.PermissionsGrants, trust mode, sensitive repos and a daily risk budget keep the dangerous switches in your hands.Audits and reviewFive audit lenses, reviewers that didn't write the code, and skeptics that try to refute every finding.Builder lanesIndependent tasks run in parallel git worktrees, each reviewed before Foreman merges it.Drive and headlessDrive mode, full auto, fm run and fm serve keep work moving without you watching.Stack cardsOver a thousand stack cards with exact verify commands, failing-test recipes and the mistakes models make.The panelThe foreman-ui mod draws the task, the stage rail, agents, activity and charts in the session itself.SpeedOnly the guard runs synchronously; everything else records asynchronously or once per turn.LearningKnown fixes, lessons, tripwires and a self-improvement loop turn friction into fixes.ToolsBatch edits, history tracing, time travel and branch tours.Foreman Codefm code runs Foreman's stations itself, so small and local models only fill small checked slots.BenchmarksReal runs, published whichever way they fall: dangerous commands, and real tasks graded blind.ReleasesEvery release passes the full gates and a release check before it reaches main.
