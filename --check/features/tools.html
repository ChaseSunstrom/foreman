Tools

Small tools that save whole turns

A handful of commands do in one call what usually takes several turns.

The ones you'll use

  • fm edit applies a batch of exact replacements across files, all or none.
  • fm why FILE:LINE traces a line back to the task and the words you asked in.
  • fm at T-0042 -- pytest runs any command as of a task's start.
  • fm tour --since main ranks a branch by review risk and says what's safe to skim.
  • fm digest sums up the week.
