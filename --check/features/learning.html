Learning

It learns a fix once, and improves itself

When a command fails and a later one gets past it, Foreman keeps the pair. The next session that meets the same failure gets the fix in the failure message, in any project on the machine.

Where improvements come from

  • Lessons written at each close and shown to the next task that touches the same code.
  • Friction passes that mine real guard refusals and repeated manual work into tasks.
  • Backtests. fm backtest shows how often a rule change would have fired on your real sessions before it ships.
  • Foreman on Foreman. It is built with itself; the charts on these pages are that record.
