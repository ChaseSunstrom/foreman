Builder lanes

Many hands, one foreman

Independent tasks go to builder subagents, each in its own git worktree with a brief that says exactly what to build, how to test it and what not to touch.

From brief to merge

  • Brief. fm lane brief ID writes the contract: the base commit, test first, the files it may change, the defects reviewers keep finding.
  • Review. An independent reviewer reads the branch; findings go back to the builder.
  • Merge. fm lane merge runs the task's criteria first and refuses a red branch.
  • Resume. A stopped session picks its lanes back up.
