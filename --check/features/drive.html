Drive and headless

It keeps going until the queue is done

Drive mode works through the whole queue. In full auto Claude decides, records why, and saves what only you can approve for one summary at the end.

Ways to run unattended

  • Drive. The Stop hook names the next task, so a session doesn't stop while work remains.
  • fm run works the queue in fresh headless sessions, one task each, and waits out usage limits.
  • fm serve runs Claude Code Remote Control on a server as a service, so you can send work from your phone.
  • fm loop on keeps improving without being asked: build a round, review it, brainstorm on top, repeat.
