Stack cards

It knows your stack, and costs no context until it matters

Each card gives the commands that verify the work, a failing-test recipe, the mistakes models actually make and a review checklist. Cards cost nothing until a matching file is edited.

Picked by what you touch

fm lib picks the cards that match your repo's manifests and files. The first edit of a file a card covers brings in that card's pitfalls, once per session; a file that imports a framework gets that framework's card too. fm lib source add indexes another skills repo read-only.
