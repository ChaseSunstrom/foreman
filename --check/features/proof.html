Proof

Nothing is done until a command proves it

Saying the tests pass is not evidence. Foreman records the real command, its exit code and its output, and refuses to close a task without it.

How a task closes

  • Evidence per step. fm task evidence --run runs the check and stores what happened.
  • Red, then green. fm task prove runs the test on the starting tree and on the changed one, and shows it fails without the change.
  • Gates. fm check runs the project's gates and reuses a pass on an identical tree.
  • One call to close. fm task finish checks the evidence, the audits, the docs note and the lesson the task's size needs, then commits its own files.
