Releases

Shipped in small, gated releases

fm release runs the ritual as nine named steps with a checkpoint after each: gates, version bumps, changelog, commit, release check, push, round close and a canary in every local project.

What a release proves

  • The full gates on the exact commit that is pushed, never later work.
  • A release check: doctor and the demo in a throwaway home.
  • Your yes to push, spent by that one push.
  • Resumable. A stop at any step continues from there with --resume.
