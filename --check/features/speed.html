Speed

Light enough to forget it's there

Hooks run on every tool call, so each has a time budget and the bench holds them to it. Only the guard and the write validators run in the call's path.

How it stays fast

  • Budgets per hook, checked by bench_hooks.py on every release.
  • Reused gate passes. fm check skips a gate that passed on an identical tree.
  • Cached verdicts. Scripts the guard read are cached by content.
  • Notes once. Context is injected only when it changes what Claude should do next.
